## 📌 Featured projects

### 📖 Easy Read — AI-assisted study PWA (team project)
An installable study app that works offline, built by a team of 5 students.
I was responsible for the **PWA / offline layer**:
- Configured `vite-plugin-pwa` with automatic service worker updates
- Set up offline caching with Workbox (precache grew from 5 to 14 files, SPA navigation fallback, old cache cleanup)
- Created the web app manifest (standalone display, 192x192 and 512x512 icons), making the app installable
- Validated everything with build/preview, Chrome DevTools and Netlify Deploy Previews: the app installs on Chrome and opens with the server stopped
- Worked in a team Git workflow: one branch per task, `feat:` commit convention, Pull Requests reviewed by the team lead, and Trello for task management

**Tech:** Vue 3 · TypeScript · Vite · PWA · Workbox · Dexie (IndexedDB) · Netlify
🔗 [Repository](https://github.com/Helio-Junior0/easy-read) · [Live demo](https://easyreadbrazil.netlify.app)
